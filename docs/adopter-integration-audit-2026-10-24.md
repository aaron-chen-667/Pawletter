# 领养者端与救助站端联调审计

审计时间：2026-10-24（北京时间）。对象为正式站点及当前 `codex/team-collaboration` 分支，应用基线提交 `2ad78be`，Sites 源码 `eb35b8c061e2e5402beacf7aefae21d3822cefa2`。本次是现状审计，没有发布业务修复。

**结论：不能宣称全部模块有后端、两端全部打通或全部联调通过。** 当前已接通核心档案、单轮 AI 问答及申请后端，但存在注册阻断、前端刷新缺陷和多个仍属本地演示的业务环节。

## 验证方式与边界

- 阅读正式入口 `frontend/dist/entry.js`、领养者 `app.js`、救助站 `online.js`、两端 API 适配器及全部后端路由。
- 正式 API 实测：健康/数据库就绪、17 只公开宠物和 51 条有效归档、两个域名的注册链路入口、QA 登录、申请列表、站点回访列表、三只宠物真实 AI 和聊天历史、真实音频转写。
- 后端 `npm test`：25 项通过。前端：44 项通过。前端在依赖完整的 `pet-adoption-demo` 运行，已逐文件比较 `dist/*.js` 与 canonical frontend，无差异。canonical 首次运行缺少 jsdom，因此那次环境失败不能算功能失败或通过。
- 新增诊断脚本复现申请刷新、消息列表及下架宠物问题；这些是已确认缺陷，不因为常规测试通过而忽略。
- 当前浏览器自动化不可用，未完成线上浏览器逐页视觉验收，也未完成手机摄像头、麦克风权限和弱网实机验收。
- 线上第一轮中途发生客户端 `URLError`；后续 `/ready` 恢复 200，重新登录后继续。不能据此认定后端停机。
- 本轮没有使用用户个人账号，没有修改真实宠物、真实申请或用户密码。真实 AI 的三个问题保存在专用 QA 会话中。

## 已确认问题与优先级

### P0：注册与画像入口被误拦截

`backend/src/app.js:74、82、87` 仍使用 `req.headers.origin === origin`。生产 `origin` 已配置为两个域名的逗号分隔字符串。浏览器请求只能携带一个 Origin，因此两个合法站点均被拒绝。

实际对两个域名、三个端点发送不产生数据的空请求，全部返回 `403 ORIGIN_REQUIRED`，而正常进入 schema 校验应为 400。CORS 预检成功并不能证明业务层 Origin 校验成功。语音端点已使用 `allowedOrigins.includes(...)`，其行为与这三处不一致。

应先统一白名单校验，新增两个域名覆盖访谈/画像/注册的真实请求测试，再重跑整个新用户流程。

### P1：可见但没有真正完成的业务路径

1. **进度不刷新**：`loadApplications()` 仅在账号接受/恢复时调用。诊断中服务器模拟从 stage=0 变成 1，用户重新进入进度页仍显示待审核，总申请请求数仍是 1。
2. **消息不恢复**：同样的冷启动诊断中云端已有通知，但消息列表请求聊天历史次数为 0，界面显示“还没有开始聊天”。
3. **下架档案导致历史页错误**：已有申请且 catalog 不包含该宠物时，复现 `Cannot read properties of undefined (reading 'image')`。
4. **用户回访假同步**：`submitCheckin()` 未调用后端，却提示已同步给站点。应先移除不实成功反馈或限制入口，再补双方计划、提交、读取、确认及素材权限。
5. **交接边界**：核验服务此前明确暂缓；服务端禁止 pending 用户完成交接是现有保护，但产品目前没有完整操作路径。需要确定可用的核验/人工审核方案，不能直接将用户批量标成 verified。
6. **旧测试账号**：QA adopter 登录接口成功，但 `GET /v1/adopter/profile` 返回 PROFILE_NOT_FOUND；必须补齐测试数据，否则无法声称普通用户端测试已经跑通。
7. **模型多轮上下文缺失**：聊天记录虽然入库，生成下一答时没有读取历史传给模型。需与已完成的宠物知识记忆分别验收。

### 后续补齐

跨设备收藏与偏好、真实用户头像与资料更新、用户回访多媒体、评价/申诉、公开动态授权、云端消息列表与未读、后台通知、领养者宠物画廊、正式站点主页/入驻和历史分页。前端已有布局不代表这些接口已存在。

- 本轮完整申请创建/推进/交接：**未完成**，原因是 QA 资料缺失与新注册被拦；25 项后端测试中的相应模拟数据库验证不能替代线上验收。
- 最后重跑的两个 QA 会话退出均 200。首轮网络故障时两个会话退出未确认，token 未写入文件，按服务配置 8 小时到期；没有登录用户个人账号。
