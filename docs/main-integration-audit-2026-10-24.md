## 修复与验收顺序

1. **版本配套**：核对并迁移 `users.read_all_stations`、`observations.observed_on/has_visuals`、`media.observation_id` 及约束；发布后端并明确切换流量，再发布对应前端。仅推 main 不会更新 Sites 或 Cloud Run。
2. **恢复入口**：两个域名分别跑访谈/画像/注册、有效QA资料、站端登录、建档、日期/影像补充。真实ASR/OCR/视频分别验，不用模拟替代。
