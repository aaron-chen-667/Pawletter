## 验收证据

- 后端全套 66 项、前端全套 106 项通过；最后的微秒修复与回访保护另跑针对性回归通过。静态语法及 Git 空白检查通过。
- 隔离集成测试使用真实前端 API 适配器、Fastify 路由、PGlite SQL；AI/对象存储替身只用于该隔离测试，不能代表云端成功。
- 首轮线上 70 项检查中 69 项符合预期，1 项是未读精度问题；修复后第二轮 68 项中 67 项符合预期，已读清零和 AI 连续追问通过，1 项真实语音遭遇供应商限流 `429 SPEECH_PROVIDER_BUSY`。检查包含正确拒绝越权/非法来源，不能把总数当作同等数量的完整业务功能。
- 实名 pending 用户交接返回 IDENTITY_PENDING。仅隔离测试通过测试夹具覆盖已核验后的交接/站内回访，**没有在生产绕过实名**。
- 真实 AI 测试使用 3 只已有宠物和专用 QA；连续追问成功回忆之前的回家时间。真实 WAV 首轮 200、32 字，第二轮限流，按提示间隔有界重试一次仍为 `429 SPEECH_PROVIDER_BUSY`。**语音当前仍有供应商可用性阻断，不能签稳定通过**；没有无限重试、切换未授权密钥或伪造转录。公开目录 17 只宠物、51 条共享知识均可读取。
- 本地 HTTP 预览 200。浏览器自动化因 kernel assets 路径问题无法启动；未完成真实手机摄像头、麦克风权限、视频/OCR、弱网和逐页视觉复验。
- 测试申请结束、测试观察撤回、QA 宠物保持 internal 且未公开、QA 会话退出。当前没有硬删除宠物/影像接口，因此保留明确标识的内部测试档案和私有影像，不进入公开目录。
- QA 凭据及原始结果只在忽略目录 backend/.local 中保存，不进入 Git；报告不披露密码、token 或个人资料。
