## 语音故障与修复

同一段合成中文音频：直接 WAV 上传返回 200；浏览器 MediaRecorder 生成 WebM/Opus 后连续返回 429/SPEECH_PROVIDER_BUSY。不能把此结果简单解释为用户录音失败或一般限流。

注册访谈和申请补充在上传前统一解码、转换为 16kHz 单声道 PCM WAV；原录音保留供播放和重试。取消过程中完成的转换不会上传。过短、过长、无法解码的录音分别提示。

真实接口验证：浏览器生成 WebM → 新转换模块 → WAV 上传转写 200、有文字 → 访谈接口 200。使用的是合成测试音频；未使用或读取用户录音。
