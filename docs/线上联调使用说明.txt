二、实际操作
1. 用 station 账号登录，进入救助站工作台。
2. 选择“联调·吐司”，或建立新档案；发布选项决定领养者是否可见。
3. 点“给宠物补充”，选好宠物后长按录音，松开自动保存。
4. “允许宠物 Agent 引用整理结果”开启时，整理后的资料可用于回答；关闭时仅本站可见。原始录音不对领养者开放。
5. 查看录入进度，等待“已归档”。处理失败可重试，内容有误可更正或撤回。
6. 退出，使用 adopter 账号登录；打开同一只宠物，问刚录入的习惯或喜好。
7. Agent 根据该宠物资料回答，并显示引用原文、站点和记录时间；没有资料时会说明不知道。

三、AI 与资料库
AI Key、服务地址由 Secret Manager 保存，沿用接入表中的已配置服务，无需把 Key 填入网页。
模型服务是 openai-next，聊天模型 gemini-3.8-flash，语音模型 whisper-1。
每只宠物按服务端 pet ID 独立关联档案、语音来源和知识库；Agent 在服务端加载这只宠物允许共享的资料。
本轮没有建立第三方平台的独立 Agent ID，使用应用内 Agent + 模型 API + PostgreSQL 资料库的实现。
